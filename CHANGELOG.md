# Changelog

All notable changes to Wapliss WhatsApp for GitHub Copilot. Created and
maintained by netdigitaltech.

## 1.0.0 (2026-11-10)

- First release: Agent Plugins 1.0 package for VS Code, Copilot CLI and the
  GitHub Copilot app. Remote MCP server `https://wapliss.com/mcp/v1` (16 tools,
  OAuth 2.1 with dynamic client registration) and the `wapliss-whatsapp` Agent
  Skill.
- This repository is also a one-plugin marketplace (`wapliss`).
- Tested: Agent Skills lint (`@microsoft/vally` 0.21.0) and install with
  Copilot CLI 1.0.109 (1 skill and the `wapliss` HTTP MCP server registered).
